## 🎯 Usar o Sistema

### 1. Processar Lançamentos

```
1. Vá em "Importar"
2. Escolha seu arquivo Excel
3. Selecione a conta (agora com descrição!)
   Exemplo: "310514 - 11010100 - PRINCIPAL"
4. Clique em "Processar"
```

### 2. Revisar Preview

```
- Verde: Lançamento OK
- Amarelo: Aviso
- Vermelho: Erro (corrigir antes de exportar)
```

### 3. Exportar CSV

```
- Clique em "Exportar CSV"
- Arquivo baixado: [numeroConta][tipo].csv
- Importar no Nasajon Contábil
```
